# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),

## [1.2.0] - 2026-09-23

### Added
- Added missing utility functions and corresponding tests.
- Added `compressImageToWebp` to the file utilities.

### Changed
- Enhanced number and string utility documentation and test coverage.
- Improved error normalization and handling across utilities.
- Improved equality checks, including support for circular references.
- Enhanced logging behavior across various utilities.
- Improved documentation and tests for `isEqual` and `capitalize`.
- Refined API reference and guide documentation for accuracy and clarity.
- Enhanced overall test coverage.
- Updated package metadata and usage guides.

### Removed
- Removed duplicate functionality.
